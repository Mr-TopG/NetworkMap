# Network equipment illustrations

Original SVG artwork created for NetworkMap. These are small, self-contained,
transparent-background network diagram illustrations with a shared muted blue
palette and simple perspective. Each uses a `0 0 96 72` view box and contains no
external resources, fonts, scripts, or shared element IDs.

Available device names:

- `router.svg` — router with directional arrows
- `switch.svg` — Ethernet switch with front-panel ports
- `server.svg` — server with three drive bays
- `workstation.svg` — desktop monitor, keyboard, and tower
- `laptop.svg` — laptop computer
- `mobile.svg` — mobile phone
- `access-point.svg` — wireless access point
- `firewall.svg` — firewall with shield
- `printer.svg` — network printer
- `camera.svg` — network camera
- `storage.svg` — shared storage/database
- `nas.svg` — two-bay network storage
- `iot.svg` — connected embedded device
- `cloud.svg` — cloud/network connection
- `other.svg` — generic network appliance

The artwork follows familiar network diagram conventions. It does not contain
Cisco logos, trademarks, or copied Cisco artwork, and is not affiliated with or
endorsed by Cisco or another equipment vendor.
